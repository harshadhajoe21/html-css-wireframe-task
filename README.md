# Wireframe to Responsive Static Web Page

## Project Description

This project converts a wireframe concept into a functional and responsive static webpage using HTML5 and CSS3.

The webpage contains a header, navigation bar, hero section, about section, services section, development process, contact section, and footer.

## Objective

The main objective of this project is to understand how a visual wireframe can be converted into a structured webpage using HTML and CSS.

The project also focuses on responsive design and testing the webpage on different screen sizes.

## Technologies Used

- HTML5
- CSS3
- CSS Media Queries
- Flexbox
- CSS Grid
